# AI Interviewer Simulator

An AI-powered system that simulates real interview scenarios by generating dynamic questions and evaluating user responses.

## 🚀 Features

* Adaptive interview questions
* AI-based answer evaluation
* Feedback on technical and communication skills

## 🛠 Tech Stack

* FastAPI (Backend)
* React (Frontend)
* PostgreSQL (Database)
* OpenAI API (AI Engine)

## ▶️ How to Run

1. Clone the repo
2. Install dependencies
3. Run backend using FastAPI
